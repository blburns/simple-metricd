simple-metricd - Read Me

Quick Start

After installation, simple-metricd will be available as a system service.

Configuration

Edit the configuration file:

/etc/simple-metricd/simple-metricd.conf

Service Management

Start the service:

sudo systemctl start simple-metricd

Enable at boot:

sudo systemctl enable simple-metricd
